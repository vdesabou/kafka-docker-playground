==========================
InfluxDB
==========================
🔘 influxdb.url

Fully qualified InfluxDB API URL used for establishing connection.

	 - Type: STRING
	 - Default: null
	 - Importance: HIGH
	 - Required: true

🔘 influxdb.username

InfluxDB username on whose behalf database connection has to be established.

	 - Type: STRING
	 - Default: null
	 - Importance: MEDIUM
	 - Required: false

🔘 influxdb.password

The InfluxDB user's password used for establishing database connection.

	 - Type: PASSWORD
	 - Default: [hidden]
	 - Importance: MEDIUM
	 - Required: false

influxdb.log.level

==========================
Write
==========================
🔘 influxdb.db

The InfluxDB database name in which connector will write records from Apache Kafka topic.

	 - Type: STRING
	 - Default: null
	 - Importance: LOW
	 - Required: false

🔘 measurement.name.format

A format string for the destination measurement name, which may contain '${topic}' as a placeholder for the originating topic name.
For example, ``kafka_${topic}`` for the topic 'orders' will map to the measurement name 'kafka_orders'.

	 - Type: STRING
	 - Default: null
	 - Importance: MEDIUM
	 - Required: false

🔘 event.time.fieldname

The name of field in the Kafka record that contains the event time to be written to anInfluxDB data point. By default (if this config is unspecified), the timestamp written to InfluxDB is the Kafka record timestamp (when the Kafka record was created) which corresponds to the time that the event was processed.

	 - Type: STRING
	 - Default: null
	 - Importance: MEDIUM
	 - Required: false

🔘 influxdb.timeunit

The default timeunit for writing data to InfluxDB.

	 - Type: STRING
	 - Default: MILLISECONDS
	 - Importance: MEDIUM
	 - Required: false

🔘 influxdb.consistency.level

The default consistency level for writing data to InfluxDB.

	 - Type: STRING
	 - Default: ONE
	 - Importance: LOW
	 - Required: false

🔘 retry.backoff.ms

Backoff time duration to wait before retrying

	 - Type: INT
	 - Default: 1000
	 - Importance: MEDIUM
	 - Required: false

🔘 max.retries

The maximum number of times to retry on errors before failing the task.

	 - Type: INT
	 - Default: 10
	 - Importance: MEDIUM
	 - Required: false
