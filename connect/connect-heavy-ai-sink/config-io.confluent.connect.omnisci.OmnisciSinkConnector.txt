==========================
Data Mapping
==========================
🔘 table.name.format

A format string for the destination table name, which may contain '${topic}' as a placeholder for the originating topic name.

	 - Type: STRING
	 - Default: ${topic}
	 - Importance: MEDIUM
	 - Required: false

==========================
Connection
==========================
🔘 connection.password

OmniSci connection password

	 - Type: PASSWORD
	 - Default: null
	 - Importance: HIGH
	 - Required: false

🔘 connection.database

OmniSci database name.

	 - Type: STRING
	 - Default: null
	 - Importance: HIGH
	 - Required: true

==========================
Writes
==========================
🔘 batch.size

Specifies how many records to attempt to batch together for insertion into the destination table, when possible.

	 - Type: INT
	 - Default: 3000
	 - Importance: MEDIUM
	 - Required: false

==========================
Retries
==========================
🔘 max.retries

The maximum number of times to retry on errors before failing the task.

	 - Type: INT
	 - Default: 10
	 - Importance: MEDIUM
	 - Required: false

🔘 retry.backoff.ms

The time in milliseconds to wait following an error before a retry attempt is made.

	 - Type: INT
	 - Default: 3000
	 - Importance: MEDIUM
	 - Required: false

==========================
Data Mapping
==========================
🔘 fields.whitelist

List of comma-separated record value field names. If empty, all fields from the record value are utilized, otherwise used to filter to the desired fields.

	 - Type: LIST
	 - Default: 
	 - Importance: MEDIUM
	 - Required: false

SQL/DDL Support

🔘 auto.evolve

Whether to automatically add columns in the table schema when found to be missing relative to the record schema by issuing ``ALTER``.

	 - Type: BOOLEAN
	 - Default: false
	 - Importance: MEDIUM
	 - Required: false
