==========================
Key
==========================
🔘 key.mode

The key mode, Supported modes are:
``kafka``    topic name, partition, offset is used for gemfire key.
``record_key``
    Field(s) from the record key are used, which may be a primitive or a struct.
``record_value``
    Field(s) from the record value are used, which may be a primitive or a struct.

	 - Type: STRING
	 - Default: kafka
	 - Importance: HIGH
	 - Required: false

🔘 key.fields

List of comma-separated with whitespace key field names. The runtime interpretation of this config depends on the ``key.mode``:
``kafka``
    key fields are ignored in this mode.``record_key``
    if empty, all the fields from key struct will be part of gemfire key, or else only the configured keys are extracted and set as gemfire key.
``record_value``
    if empty, all the fields from value struct will be part of gemfire key, or else only the configured keys are extracted and set as gemfire key.


	 - Type: LIST
	 - Default: 
	 - Importance: HIGH
	 - Required: false

==========================
Writes
==========================
🔘 delete.enabled

Whether to treat ``null`` record values as deletes. Requires ``key.mode`` to be ``record_key``.

	 - Type: BOOLEAN
	 - Default: false
	 - Importance: MEDIUM
	 - Required: false

🔘 batch.size

Maximum number of records to be batched in a single insert operation.

	 - Type: INT
	 - Default: 100
	 - Importance: MEDIUM
	 - Required: false
