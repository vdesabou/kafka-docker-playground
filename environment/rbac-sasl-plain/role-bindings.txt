# Default role bindings of the rbac-sasl-plain environment, created by start.sh with:
#   playground rbac role-binding create --file role-bindings.txt
#
# One role binding per line: <principal> <role> <resource> [prefix] [scope=<scope>]
#   resource  <ResourceType>:<name>, or - for a role bound on the whole cluster
#   prefix    the resource name is a prefix (PREFIXED pattern)
#   scope     kafka, schema-registry, connect or ksqldb. If not set, it is deduced from the resource type:
#             Subject is schema-registry, Connector is connect, KsqlCluster is ksqldb, anything else is kafka
#
# Cluster names: kafka-cluster (Kafka), schema-registry, connect-cluster, ksql-cluster
