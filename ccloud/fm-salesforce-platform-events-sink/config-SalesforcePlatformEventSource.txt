==========================
Kafka Cluster credentials
==========================
🔘 kafka.auth.mode

Kafka Authentication mode. It can be one of KAFKA_API_KEY or SERVICE_ACCOUNT. It defaults to KAFKA_API_KEY mode, whenever possible.

	 - Type: STRING
	 - Default: ${connect.regional.connector}
	 - Importance: HIGH
	 - Required: false

🔘 kafka.service.account.id

The Service Account that will be used to generate the API keys to communicate with Kafka Cluster.

	 - Type: STRING
	 - Default: 
	 - Importance: HIGH
	 - Required: false

🔘 kafka.api.key

Kafka API Key. Required when kafka.auth.mode==KAFKA_API_KEY.

	 - Type: PASSWORD
	 - Default: 
	 - Importance: HIGH
	 - Required: false

🔘 kafka.api.secret

Secret associated with Kafka API key. Required when kafka.auth.mode==KAFKA_API_KEY.

	 - Type: PASSWORD
	 - Default: 
	 - Importance: HIGH
	 - Required: false

🔘 datapreview.schemas.enable

This config key only applies to data preview requests and governs whether the data preview output has record schema with it.
The visibility condition is set such that it can never be true.
So this key does not show in create connector UI.

	 - Type: STRING
	 - Default: false
	 - Importance: LOW
	 - Required: false

==========================
Schema Config
==========================
🔘 schema.context.name

Add a schema context name. A schema context represents an independent scope in Schema Registry. It is a separate sub-schema tied to topics in different Kafka clusters that share the same Schema Registry instance. If not used, the connector uses the default schema configured for Schema Registry in your Confluent Cloud environment.

	 - Type: STRING
	 - Default: default
	 - Importance: MEDIUM
	 - Required: false

How should we connect to Salesforce?
==========================
🔘 salesforce.grant.type

Grant type the connector uses for Salesforce authentication: PASSWORD, CLIENT_CREDENTIALS, JWT_BEARER, or OAUTH2_AUTH_CODE_BYOA (OAuth 2.0 Authorization Code with your own connected app). Note: Salesforce is retiring the username-password OAuth flow in Spring '27; please consider migrating to other supported authentication methods.

	 - Type: STRING
	 - Default: PASSWORD
	 - Importance: HIGH
	 - Required: false

🔘 salesforce.instance

	 - Default: https://login.salesforce.com

==========================
Connection details
==========================
🔘 salesforce.initial.start

Specify the initial starting point for the connector. Allowed values are
latest: only read events that arrive after the connector has started.
all: read all events including past events from the beginning of the Event Bus.
The default value is latest.

	 - Type: STRING
	 - Default: latest
	 - Importance: MEDIUM
	 - Required: false

🔘 connection.timeout

The amount of time to wait in milliseconds while connecting to the Salesforce streaming endpoint.

	 - Type: LONG
	 - Default: 30000
	 - Importance: LOW
	 - Required: false

🔘 request.max.retries.time.ms

Maximum time in milliseconds until the connector stops retrying failed Salesforce requests. Default is 30000 and minimum is 1000.

	 - Type: LONG
	 - Default: 30000
	 - Importance: LOW
	 - Required: false
