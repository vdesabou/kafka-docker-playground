# Benchmark ksqlDB queries

## Objective

Measure the throughput of 5 typical ksqlDB persistent queries on data generated by Datagen connectors (topics `orders`, `shipments`, `products`, `customers`).

| Query | Stream / table | Shape |
| --- | --- | --- |
| 0 | `FILTERED_STREAM` | filter (`WHERE productid='Product_1' or productid='Product_2'`) |
| 1 | `ENRICHED_O_C` | stream-table `LEFT OUTER JOIN` (orders with customers) |
| 2 | `ENRICHED_O_C_P` | stream-table `LEFT JOIN` on the result of query 1 (with products) |
| 3 | `ORDERS_SHIPPED` | stream-stream `INNER JOIN ... WITHIN 2 HOURS` (orders with shipments) |
| 4 | `ORDERPER_PROD_CUST_AGG` | aggregation `GROUP BY PRODUCTID, CUSTOMERID` (`KEY_FORMAT='JSON'`: a key of 2 columns needs a key format with a schema) |

For each query, the script prints the number of records processed, the duration and the throughput, for example (CP 8.4.0, a laptop):

```
🚀 Stream ORDERS_SHIPPED has processed 1000000 messages. Took 11 seconds. Throughput=90909 msg/s
```

## How to run

```bash
playground run -f start<tab>
```

To compare ksqlDB versions, run it with `--tag <version>`.
